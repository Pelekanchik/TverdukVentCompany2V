## 🚀 Швидкий старт

### 1. Встановлення залежностей

```bash
pip install -r requirements.txt
```

### 2. Запуск програми

```bash
# GUI режим
python main.py

# Консольний режим
python main.py --cli
```

### 3. Встановлення як пакету

```bash
pip install -e .
vent-firm      # CLI
vent-firm-gui  # GUI
```

### 4. Повна демонстрація

Введіть `demo` в головному меню CLI для автоматичного запуску повної демонстрації всіх модулів.

### 5. Тестування

```bash
python -m unittest discover tests
```

## 📐 Модуль 1: Побудова проєкту

### Можливості:
- **Створення проєкту** з усіма параметрами
- **Каталог компонентів** — вентилятори, фільтри, клапани тощо
- **Каталог матеріалів** — оцинкована сталь, нержавіюча сталь, ізоляція
- **Розрахунок повітропроводів** — прямокутні та круглі
- **Автоматична специфікація**
- **Експорт** у JSON, TXT, ZIP

## 💰 Модуль 2: Розрахунки

### 2.1 Розрахунок вартості
- Собівартість, націнка, ПДВ, кінцева ціна
- Прибуток та рентабельність

### 2.2 Зарплатний фонд
- Розрахунок по посадах
- Премії, податки (ПДФО 18%, військовий збір 1.5%, ЄСВ 22%)
- Чиста зарплата «на руки»

### 2.3 Облік витрат
- Категорії: сировина, комплектуючі, зарплата, електроенергія тощо

### 2.4 Ціноутворення
- **Cost-plus**, **Competitive**, **Value-based**

## 📊 Модуль 3: Архів та аналітика

- Архівування в ZIP
- Фінансова аналітика
- Статистика виробництва
- Звіти (фінансовий, по проєктам, по зарплаті, зведений)

## 🎨 Додаткові модулі

- **CAD-редактор** — 2D креслення з прив'язкою, вимірами, шарами
- **Розкрій листа** — алгоритм розкладки Bottom-Left heuristic
- **Калькулятор виробів** — детальний розрахунок з фланцями та накладними

## ⚙️ Конфігурація

Всі налаштування в `ventilation_company/config.py`:

```python
MARKUP_PERCENTAGE = 30      # Націнка %
VAT_RATE = 20               # ПДВ %
OVERHEAD_PERCENTAGE = 15    # Накладні витрати %
```
