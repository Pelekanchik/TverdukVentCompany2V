# 🖥️ VentCompany PySide6 — Скелет програми

## Структура

```
pyside6_skeleton/
├── main_pyside6.py                          # Точка входу
├── requirements_pyside6.txt                 # Залежності
└── ventilation_company/
    └── gui_pyside6/
        ├── __init__.py
        ├── theme.py                         # Темна тема (Catppuccin Mocha)
        ├── login_dialog.py                  # Вікно входу
        ├── sidebar.py                       # Бічна панель
        ├── main_window.py                   # Головне вікно
        ├── dashboard_tab.py                 # Дашборд з картками
        └── projects_tab.py                  # Таблиця проєктів (QTableView)
```

## 🚀 Запуск

### 1. Встановіть PySide6

```bash
pip install PySide6>=6.6.0
```

### 2. Скопіюйте файли

Покладіть папку `gui_pyside6/` у ваш проєкт:
```
TverdukVentCompany2V/
├── main_pyside6.py
├── ventilation_company/
│   ├── gui_pyside6/          ← сюди
│   ├── database/
│   ├── services/
│   └── ...
```

### 3. Запустіть

```bash
python main_pyside6.py
```

## 🎨 Що вже працює

| Компонент | Опис |
|-----------|------|
| **Темна тема** | Catppuccin Mocha — сучасні кольори, закруглені елементи |
| **Вікно входу** | Логін/пароль, інтеграція з `AuthService` |
| **Бічна панель** | Іконки, групи, активний пункт підсвічується |
| **Дашборд** | 4 картки статистики + місце для графіків |
| **Таблиця проєктів** | QTableView з сортуванням, пошуком, даними з PostgreSQL |

## 📋 Що додати далі

1. **Вкладка "Вироби"** — таблиця з фільтрами по типу/матеріалу
2. **Вкладка "Специфікація"** — дерево (QTreeView) з групуванням
3. **Вкладка "Розкрій"** — візуалізація плану розкрою (QPainter)
4. **Графіки** — QtCharts для дашборду
5. **Друк/PDF** — QPrinter для звітів
6. **Перетягування** — Drag-and-drop для виробів у проєкт

## 🎯 Порівняння з tkinter

| Функція | tkinter | PySide6 |
|---------|---------|---------|
| Таблиці | Кострубаті | Нормальні (сортування, фільтри) |
| Темна тема | Вручну | "З коробки" |
| Графіки | matplotlib | QtCharts (вбудовані) |
| Друк | Складно | QPrinter (просто) |
| Швидкість | Повільна | Швидка (C++ backend) |
| Розмір .exe | ~15 МБ | ~40 МБ (з Qt DLL) |

## 💡 Порада

Запустіть `main_pyside6.py` паралельно зі старою програмою. Поступово переносьте
вкладки з tkinter у PySide6. Не переписуйте все одразу — це ризиковано.
